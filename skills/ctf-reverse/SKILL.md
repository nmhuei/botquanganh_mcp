# ctf-reverse

## Description

Reverse engineering skill — compiled binaries, crackmes, packed targets, custom
VMs, bytecode, Android APKs, WASM, firmware, game clients, anti-debugging,
obfuscation, and flag checkers.

Use this skill when the main task is understanding how the artifact works before
writing an exploit or deriving input.

## Prerequisites

```bash
python3 -m pip install angr qiling unicorn capstone keystone-engine lief z3-solver frida-tools r2pipe uncompyle6 pyelftools --break-system-packages
apt-get install -y file binutils gdb gdb-multiarch radare2 strace ltrace upx apktool jadx
```

Optional GUI tools: Ghidra, IDA Free, Binary Ninja, Cutter.

## Recon Checklist

```bash
file artifacts/*
strings -a artifacts/* | tee recon/strings.txt
strings -a artifacts/* | grep -iE 'flag|ctf|key|pass|wrong|correct|secret'
readelf -h artifacts/binary 2>/dev/null
readelf -s artifacts/binary 2>/dev/null | head
checksec --file=artifacts/binary 2>/dev/null || true
strace -f -s 500 ./artifacts/binary 2>&1 | tee recon/strace.txt
ltrace -f -s 500 ./artifacts/binary 2>&1 | tee recon/ltrace.txt
```

## First-Pass Workflow

1. Identify format and architecture.
2. Search plaintext strings and embedded resources.
3. Run once with dummy input.
4. Trace syscalls/library calls.
5. Find validation function or final comparison.
6. Determine whether flag is:
   - stored plaintext
   - generated at runtime
   - expected user input
   - decrypted after correct key
   - behind anti-debug/packer
7. Script the solve. Avoid manual-only answers.

## Common Patterns

### Plain compare

Signals:

```text
strcmp, strncmp, memcmp, puts("correct"), puts("wrong")
```

Actions:

```bash
ltrace ./binary
gdb ./binary
b strcmp
b memcmp
run
x/s $rdi
x/s $rsi
```

### Transform then compare

Build inverse:

```python
target = bytes.fromhex("...")
flag = bytes((b ^ i ^ 0x42) & 0xff for i,b in enumerate(target))
print(flag)
```

### Let program compute it

Break just before comparison:

```gdb
start
b *main+OFFSET
run
x/s $rdi
x/s $rsi
x/64bx $rsp
```

### angr path solve

```python
import angr, claripy

proj = angr.Project("./artifacts/binary", auto_load_libs=False)
flag = claripy.BVS("flag", 8*64)
state = proj.factory.full_init_state(args=["./artifacts/binary"], stdin=flag)
for b in flag.chop(8):
    state.solver.add(b >= 0x20, b <= 0x7e)

simgr = proj.factory.simgr(state)
simgr.explore(find=lambda s: b"Correct" in s.posix.dumps(1),
              avoid=lambda s: b"Wrong" in s.posix.dumps(1))
print(simgr.found[0].solver.eval(flag, cast_to=bytes))
```

### Frida hook

```javascript
Interceptor.attach(Module.getExportByName(null, "strcmp"), {
  onEnter(args) {
    console.log("strcmp", args[0].readCString(), args[1].readCString());
  }
});
```

Run:

```bash
frida -f ./artifacts/binary -l hook.js
```


## Anti-Debug Checklist

- `ptrace`
- `/proc/self/status`
- timing checks
- signal handlers
- self-modifying code
- packed UPX
- Frida detection
- debugger process name checks

Bypasses:

```bash
strace -f ./binary
ltrace -f ./binary
gdb -ex 'set follow-fork-mode child' ./binary
LD_PRELOAD=./bypass.so ./binary
```

## Verify

A reverse flag is valid only when:

- The original binary prints success for the recovered input, or
- The recovered plaintext is decrypted/generated by the original binary logic, or
- The remote checker accepts it.

Always save:

```bash
printf '%s\n' "$FLAG" | ./artifacts/binary | tee evidence/local-verify.txt
```

## Pivot Rules

- Memory corruption after understanding logic → `ctf-pwn`
- Crypto implementation with recovered parameters → `ctf-crypto`
- APK talks to API → `ctf-web`
- Firmware filesystem/data carving → `ctf-forensics`
- VM/jail puzzle → `ctf-misc`
